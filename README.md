</div>💛 Sobre o projeto
O Blindbee é um site acadêmico desenvolvido com foco na inclusão e na acessibilidade digital. A proposta é oferecer um ambiente de apoio ao aprendizado de inglês para pessoas com deficiência visual, utilizando uma navegação clara, recursos interativos e apoio à leitura.

O projeto também reúne informações sobre a iniciativa, atividades educativas e formas de participação. Trata-se de um protótipo educacional, não de uma plataforma comercial.
✨ Recursos e funcionalidades
- Navegação por teclado: uso de Tab para percorrer elementos e Enter para ativá-los.
- Apoio à leitura: opção de ativar narração em partes do site, quando houver suporte do navegador.
- Aulas e exercícios: conteúdos de inglês com atividades interativas.
- Biblioteca multimídia: espaço para áudio, vídeo legendado e conteúdos incorporados.
- Conteúdos organizados: seções de notícias, perguntas frequentes, projetos e informações institucionais.
- Layout responsivo: pensado para acesso em diferentes tamanhos de tela.
Nota de acessibilidade: o suporte a recursos como síntese de voz pode variar conforme o navegador e o dispositivo. O Blindbee é um projeto em desenvolvimento, e esta descrição não representa uma certificação de conformidade com WCAG.

- HTML5 — estrutura das páginas.
- CSS3 — identidade visual e adaptação a diferentes telas.
- JavaScript — interatividade e recursos de apoio à navegação e leitura.
🚀 Como executar localmente
1. Baixe ou clone este repositório.
2. Mantenha a estrutura original dos arquivos, especialmente a pasta assets.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo index.html com a extensão Live Server ou um servidor HTTP local.
Se tiver Python instalado, execute na pasta do projeto:
python -m http.server 8000
Depois, acesse http://localhost:8000/ no navegador.
♿ Como navegar
1. Utilize Tab para avançar entre links, botões e campos.
2. Pressione Enter para ativar o elemento selecionado.
3. Quando disponível, utilize o botão Ativar leitura para ouvir a narração opcional.
4. Explore a seção Projetos para acessar as atividades de inglês.
🎓 Contexto acadêmico
Projeto desenvolvido para uma atividade acadêmica da Universidade Cidade de São Paulo (UNICID), unindo desenvolvimento front-end, usabilidade e inclusão digital.

- A página de doações não processa pagamentos reais.
