# Publicar o Blindbee pelo GitHub Pages (HTTPS)

1. Abra a pasta do projeto no VS Code; verifique se `index.html` e `assets/` estão na raiz.
2. Crie um repositório GitHub para a equipe e faça o primeiro commit, **com seu próprio usuário**.
3. Cada integrante faz ao menos um commit verdadeiro com mensagem descritiva.
4. Abra uma branch real, por exemplo `melhoria/acessibilidade`; crie um pull request e faça revisão, depois integre.
5. Em **Settings → Pages**, escolha a publicação de `main` / `/(root)` se disponível para o repositório, ou siga o fluxo de Actions do GitHub Pages.
6. Copie a URL `https://...github.io/...`, abra em outro dispositivo, teste as 10 páginas e corrija links relativos e caches.
7. Salve URL e repositório nos arquivos `entrega/` e no README, e inclua prints reais em `evidencias/`.

Não confunda `http://localhost` com publicação HTTPS. Não basta criar branch/PR no código sem executar as ações no GitHub.
