Blindbee — orçamento de hospedagem

Proposta acadêmica de website estático HTML, CSS e JavaScript, sem backend, login ou processamento de pagamentos.

Escolha proposta: GitHub Pages

É suficiente para páginas estáticas e facilita o vínculo entre código-fonte, histórico Git e publicação HTTPS. A publicação efetiva ainda deve ser realizada pela equipe.

Alternativas

Netlify e Vercel oferecem opções para sites estáticos sob diferentes limites; não são indispensáveis neste escopo. Se a equipe mudar o provedor, atualizar preço, justificativa e screenshots com a fonte consultada na data da entrega.

Verificação externa

Consulte as condições atuais em Documentação oficial do GitHub Pages antes da entrega; não interpretar esta proposta como publicação realizada.
